Backup

The site's code and scorecard history already live on GitHub and would survive a total Cloudflare loss on their own. This page backs up the one thing that doesn't: the live database — player profiles, registrations, dues records, event payouts, and stream links.

Download this periodically and save it somewhere private — OneDrive, Google Drive, a local folder. Do not put it back into the GitHub repo — it's public, and this file contains player emails and payment info.
